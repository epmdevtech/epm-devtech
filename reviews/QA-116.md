## 1. Sumário da Execução

1. **Refatoração do `middleware.ts`:**
   - Implementado mapa declarativo `PROXIES` mapeando:
     - `odontologia.epmdevtech.com.br` → `dentistry-demo.elessandrodev.workers.dev`
     - `brs.epmdevtech.com.br` → `brs-automotive-repair.elessandrodev.workers.dev`
   - Bypass imediato (`return undefined`) para hosts não mapeados (site institucional `epmdevtech.com.br`).
   - Construção do upstream preservando `url.pathname + url.search`.
   - Remoção do header `host` e inclusão de `x-forwarded-host` e `x-forwarded-proto: https`.
   - Suporte a streaming de body para requisições com mutação (POST/PUT/PATCH/DELETE) com `{ duplex: "half" }`.
   - Interceptação de respostas 30x com `redirect: "manual"` e reescrita do cabeçalho `Location` para manter o usuário no domínio público `*.epmdevtech.com.br`.
   - Aplicação uniforme dos 4 cabeçalhos de segurança corporativos (AppSec) em todas as respostas proxyadas.

2. **Testes Automatizados:**
   - Criada suíte de testes unitários dedicada em `src/__tests__/middleware.test.ts` cobrindo 7 cenários críticos:
     - Captura global de rotas via `matcher: "/(.*)"`.
     - Bypass para o domínio raiz institucional (`epmdevtech.com.br/services`).
     - Bypass para hosts não registrados (`www.epmdevtech.com.br`).
     - Proxy transparente para `odontologia.epmdevtech.com.br` com repasse de query strings e injeção de AppSec.
     - Proxy para `brs.epmdevtech.com.br` repassando body com `{ duplex: "half" }` em requisições POST.
     - Reescrita do header `Location` para evitar vazamento de URL técnica `workers.dev` em redirects 30x.
     - Preservação intacta de URLs externas (ex.: WhatsApp) no header `Location`.

## 3. Comandos de Validação Pós-Deploy

Após o deploy das alterações na Vercel, executar:

```bash
curl -I https://brs.epmdevtech.com.br
curl -I https://odontologia.epmdevtech.com.br
curl -I https://epmdevtech.com.br
```

Comportamento esperado:
- **`brs.epmdevtech.com.br`**: HTTP 200 (ou redirect 30x se aplicável ao root do worker), `server: Vercel`, headers `X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`.
- **`odontologia.epmdevtech.com.br`**: HTTP 200, `server: Vercel`, headers AppSec idênticos aos anteriores.
- **`epmdevtech.com.br`**: HTTP 200 servindo a Landing Page institucional do SPA sem interferência.
