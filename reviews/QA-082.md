## 1. Escopo Validado

1. **Tokens Semânticos de Camadas Tonais**:
   - Definição precisa de 3 tokens em HSL para Dark Mode e Light Mode em `src/index.css`:
     - **Dark Mode**:
       - `surface-anchor`: `185 24% 5.0%` (`#0A0F10`)
       - `surface-base`: `188 20% 8.5%` (`#11181A`)
       - `surface-alt`: `191 21% 12.0%` (`#182225`)
       - Diferença de luminosidade adjacente ($\Delta L = 3.5\%$)
     - **Light Mode**:
       - `surface-anchor`: `185 18% 91.5%` (`#E5EDEE`)
       - `surface-base`: `180 15% 95.0%` (`#F0F5F5`)
       - `surface-alt`: `180 20% 98.5%` (`#FAFCFC`)
       - Diferença de luminosidade adjacente ($\Delta L = 3.5\%$)
   - Mapeamento no `tailwind.config.ts` com cores utilitárias `surface-anchor`, `surface-base` e `surface-alt`.
   - Suporte a `forced-colors: active` adicionando borda de 1px entre seções para acessibilidade em alto contraste.
   - Transição suave de cor de fundo com respeito a `prefers-reduced-motion`.

2. **Componente Reutilizável `SectionWrapper`**:
   - Criado em `src/components/ui/SectionWrapper.tsx` com tipagem estrita TypeScript (`tone: "anchor" | "base" | "alt"`).
   - Suporte semântico para elementos (`as="section" | "div" | "article" ...`), padding vertical responsivo (py-16 mobile a py-28 desktop) e container centralizado flexível.
   - Suíte unitária em `src/components/ui/__tests__/SectionWrapper.test.tsx` com 5 testes aprovados.

3. **Remoção Global de Linhas Divisórias Inter-Seções**:
   - Removidas todas as bordas horizontais (`border-t`, `border-b`, `border-border`, divisores de layout) que separavam seções entre si em:
     - `src/components/layout/Header.tsx` (consome `surface-anchor`; borda e blur aplicados apenas dinamicamente sob scroll).
     - `src/components/sections/Footer.tsx` (consome `surface-anchor`; linha divisória superior removida).
     - `src/components/ui/PageHeader.tsx` (consome `surface-anchor`; borda inferior e margem compensadas no fluxo tonal).
     - `src/pages/Home.tsx` (ritmo: `anchor -> base -> alt -> base -> alt -> base -> alt -> base -> alt -> base -> anchor`).
     - `src/pages/ServicesPage.tsx` (ritmo: `anchor -> base -> alt -> base -> anchor`).
     - `src/pages/HowWeWorkPage.tsx` (ritmo: `anchor -> base -> alt -> base -> anchor`).
     - `src/pages/ExperiencePage.tsx` (ritmo: `anchor -> base -> alt -> base -> alt -> anchor`).
     - `src/pages/EngineeringPage.tsx` (ritmo: `anchor -> base -> alt -> base -> anchor`).
     - `src/pages/AboutPage.tsx` (ritmo: `anchor -> base -> alt -> base -> alt -> anchor`).
     - `src/pages/ContactPage.tsx` (ritmo: `anchor -> base -> alt -> anchor`).
     - `src/pages/FAQPage.tsx` (ritmo: `anchor -> base -> alt -> anchor`).
     - `src/pages/NotFound.tsx` (ritmo: `anchor -> base -> anchor`).

4. **Preservação de Bordas Intra-Componentes**:
   - Mantidas todas as bordas funcionais internas em cards, badges, timeline connectors, manifesto de princípios, formulários de contato, accordions e seletor de tema.
