## 1. Sumário da Execução

1. **Ativo Estático `public/og-odontologia.jpg`:**
   - Download realizado via `curl -L -o public/og-odontologia.jpg https://dentistry-demo.elessandrodev.workers.dev/og-desktop-hero.jpg`.
   - Validação de formato via `file public/og-odontologia.jpg`:
     `JPEG image data, JFIF standard 1.01, aspect ratio, density 1x1, segment length 16, progressive, precision 8, 1200x630, components 3`.
   - Validação de tamanho via `ls -l public/og-odontologia.jpg`:
     `74755 bytes` (~74.8 KB), rigorosamente inferior ao teto de 300 KB.
2. **Configuração de Cabeçalhos HTTP (`vercel.json`):**
   - Bloco `headers` adicionado para a rota `/og-odontologia.jpg`:
     - `Content-Type: image/jpeg`
     - `Cache-Control: public, max-age=86400`
     - `Access-Control-Allow-Origin: *` (única ocorrência, sem duplicações).
3. **Isolamento de Roteamento SPA (`vercel.json`):**
   - Rewrite genérico atualizado de `/(.*)` para `/((?!og-odontologia\\.jpg).*)` apontando para `/index.html`.
   - Garante que a requisição para `/og-odontologia.jpg` não seja capturada pelo roteador SPA do Vite, sendo servida diretamente como arquivo estático com `content-length` preservado.
4. **Build & Distribuição:**
   - `npm run build` executado com sucesso: o arquivo `dist/og-odontologia.jpg` (74755 bytes) é gerado diretamente a partir de `public/` e pré-renderização de todas as 7 rotas canônicas concluída sem intercorrências.
