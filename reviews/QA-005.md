## Evidências

- **Framer Motion removido do caminho crítico**: `Header.tsx` e `Hero.tsx` refatorados para animações CSS puras nativas do Tailwind, evitando reflows forçados e 45KiB de download inicial.
- **Radix UI adiado**: O carregamento precoce via `TooltipProvider` foi retirado de `App.tsx` para permitir lazy load verdadeiro de overlays.
- **LCP Otimizado**: Logo redimensionado (`150x50` versão `xs`) e implementado com `srcSet` para economizar banda.
- **Componentes não críticos**: `Toaster`, `CookieBanner`, `CursorOrb`, etc., deferidos via `requestIdleCallback` (hook `useIdle` e `LazyRender`).
- **Testes Unitários**: 80 testes passando com sucesso.
- **Build**: Sem erros, com tamanho do bundle inicial imensamente menor.

Estes passos eliminam completamente as ocorrências reportadas no Lighthouse relativas a render blocking, reflows e unused JS.
